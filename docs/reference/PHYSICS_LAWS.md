## 物理公式参考

| 特性          | 普通物体(牛顿)                                             | 光线(广义相对论近似)                                                                                                             | 说明                         |
| ------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 核心变量      | 位置 $P$ ，速度 $\vec{V}$                                  | 位置 $P$，方向 $\vec{d}$                                                                                                         |                              |
| 加速度        | $\vec{a}=-\frac{G \cdot M}{\|\vec{r}\|^3}\cdot\vec{r}$     | $\vec{a}_{GR}=-\frac{3\cdot G\cdot M\cdot h^2}{c^2\cdot\|\vec{r}\|^5}\cdot\vec{r}$                                               | $h=\|\vec{r}\times\vec{d}\|$ |
| 速度/方向变化 | $\vec{v}_{new}=\vec{v}_{old}+\vec{a}\cdot\Delta t$         | $\vec{d}_{new}=\text{normalize}(\vec{d}_{old}-\frac{3 \cdot G\cdot M\cdot h^2}{c^2\cdot\|\vec{r}\|^5}\cdot\vec{r}\cdot\Delta s)$ | $\Delta s$ 为步长            |
| 位置变化      | $\vec{P}_{new}=\vec{P}_{old}+\vec{v}_{new} \cdot \Delta t$ | $\vec{P}_{new}=\vec{P}_{old}+\vec{d}_{new} \cdot \Delta s$                                                                       |                              |
| 能量守恒      | 动能与势能相互转化                                         | 光速恒定，能量体现在角动量上                                                                                                     |                              |
